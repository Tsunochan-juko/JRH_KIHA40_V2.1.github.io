朝里重工ポータル / キハ40系パック配布ページのローカル試作

index.html をブラウザで開くとポータルが表示されます。
kiha40.html がキハ40系パックの詳細・ダウンロードページです。番台を選ぶと共通パック・音声パックと一緒にZIPを取得します。index.html のスライドショー画像は images/slideshow/ に置いています。
HTMLは外部公開していません。ZIPリンクは、この作業フォルダ内のファイルを参照します。フォントはGoogle Fontsから読み込むため、ネット接続時にBIZ UDPGothicとInter Tightが使われます。

公開前に確認する項目:
・配布先URLとバージョン表記
・Minecraft / RTM / KaizPatchX の対応バージョン
・全車両のゲーム内動作とシェーダー条件
・同梱 assets/readme.txt の利用条件との整合

掲載内容の根拠:
・ASARI_JRH_40_V2.1_semiauto/packs 内の車両JSONとREADME
・ASARI_JRH_40_V2.1_semiauto/zip 内のZIP
・[RTM]ASARI_JRH_40_soundpack.zip
